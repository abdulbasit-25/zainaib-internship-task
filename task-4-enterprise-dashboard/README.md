# Enterprise Dashboard

This project is a React-based admin portal built for managing data, users, products, and transactions in a professional dashboard layout.

It includes a login screen, protected routes, responsive navigation, and interactive cards for analytics and reporting.

The app gives a realistic enterprise feel with a clean UI, working filters, and simulation of live business data.

## Features

- Secure-style login screen with demo credentials
- Protected dashboard pages for authenticated users only
- Analytics and sales overview cards
- Users, products, and transactions management views
- Search and sorting for data tables
- Modern sidebar and top navigation layout
- Responsive design for desktop and mobile

## Tech Stack

- React
- Vite
- React Router
- Recharts
- CSS modules and custom styling

## Run the Project

1. Open the project folder.
2. Install dependencies with npm install.
3. Start the app with npm run dev.
4. Open the local URL shown in the terminal.
