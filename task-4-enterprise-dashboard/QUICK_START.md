# Enterprise Dashboard - Quick Start Guide

## Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Troubleshooting

**Page not loading?**

- Clear browser cache
- Check browser console for errors

**Charts not updating?**

- Ensure JavaScript is enabled
- Try refreshing the page

**Login not working?**

- Check credentials (case-sensitive password)
- Clear localStorage: F12 → Application → Storage → Clear All
