# Pricing Calculator

This project is a responsive pricing calculator built with HTML, CSS, and JavaScript.

It helps users estimate a total price based on unit price, quantity, tax rate, and discount tiers.

The page updates values automatically as inputs change, making it useful for product quotes and sales estimates.

## Features

- Real-time subtotal and total calculation
- Quantity-based volume discount rules
- Tax rate adjustment
- Reset button for quick recalculation
- Clean, professional invoice-style layout

## Project Goal

The goal of this task is to practice UI design and JavaScript logic together in a simple but practical tool.

## How to Run

1. Open the folder in your browser.
2. Open the index.html file directly.
3. Adjust the values and watch the totals update instantly.

This project is a small frontend demo focused on calculation logic and user-friendly presentation.
