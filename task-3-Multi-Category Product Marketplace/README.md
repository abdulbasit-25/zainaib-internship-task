# Multi-Category Product Marketplace

This project is a storefront mockup built with HTML, CSS, and vanilla JavaScript.

It allows users to browse products across several categories, filter by price, and search for items in real time.

The interface includes a cart drawer, sorting controls, and an empty-state message when no results match.

## Features

- Category-based filtering
- Search bar for quick product lookup
- Price range slider
- Sort options for price and name
- Shopping cart sidebar with totals
- Checkout confirmation modal

## Project Goal

This task demonstrates how to build a practical e-commerce interface with interactive frontend behavior.

## How to Run

1. Open the project folder.
2. Open index.html in a browser.
3. Browse products and test the filters and cart.

The project focuses on user experience, product discovery, and clean shopping UI design.
